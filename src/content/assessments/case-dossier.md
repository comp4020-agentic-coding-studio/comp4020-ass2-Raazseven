Weeks 2 through 4 build a way of telling a records problem apart from a
capability problem. This assessment asks you to run that method on a case
you find yourself, outside the reading list, and write it up as a dossier:
what was claimed to be lost, what evidence exists for the record track and
the capability track separately, and where — if anywhere — a rupture point
sits between them.

The hardest part of this assessment is usually not the analysis. It's
finding a case with enough public documentation to support the analysis at
all, and being honest in the dossier about exactly how much that
documentation actually settles.
